Developer reference

RouteWise API surface.

The production Python gateway exposes these routes. The hosted companion documents them without exposing a live API key.

Local APIRun the FastAPI service from the GitHub source to call these endpoints. The private hosted demo only executes client-side routing logic.
RoutePreviewEstimateHealth
POST

/route

Chooses a model, calls the provider, applies budget and quality policies, and returns the formatted response.

curl -X POST http://localhost:8080/route \
  -H 'Content-Type: application/json' \
  -H 'X-API-Key: your-key' \
  -d '{"messages":[{"role":"user","content":"Explain semantic caching"}]}'
POST

/route/preview

Returns the selected model and routing rationale without making a provider call.

{
  "selected_model": "gpt-4.1-mini",
  "routing_policy": "balanced",
  "estimated_complexity": 0.62
}
POST

/route/estimate

Estimates token usage, request cost, and whether the configured budget permits the route.

GET

/health

Returns a lightweight process health response for container probes.

{ "status": "ok" }
